# Attribution for the humanizer skill

## What is borrowed

The taxonomy of AI writing tells in `SKILL.md` follows the categories and observations set out in
[Wikipedia:Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing),
maintained by WikiProject AI Cleanup. Wikipedia text is licensed
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

## What is not borrowed

No prose, no "words to watch" list, and no before/after example was copied from that page. Every
sentence and every example in `SKILL.md` was written for this repository. What carries over is the
set of ideas, which CC BY-SA does not restrict, together with the credit above, which it earns.

That distinction is deliberate. CC BY-SA 4.0 is a share-alike licence and this repository ships
under MIT. Copying Wikipedia prose into an MIT-licensed file would create a licence conflict. Using
the ideas and crediting the source does not.

## If you extend this skill

Do not paste Wikipedia text in. Describe the pattern in your own words, write your own example, and
leave the credit above intact.

## Related prior art

[blader/humanizer](https://github.com/blader/humanizer) (MIT) packages the same Wikipedia guidance
as a standalone agent skill and is where the idea of doing so came from. The file in this directory
is an independent implementation, not a fork or a copy of it.
